# Specs Aula 3 - Docker Essencial

## Objetivo

Este projeto foi desenvolvido como parte da Aula 3, com foco nos conceitos essenciais de Docker e Docker Compose.

A aplicação consiste em uma API simples desenvolvida em Flask, executada em um container Docker e integrada a um banco de dados PostgreSQL.

## Tecnologias utilizadas

- Python
- Flask
- PostgreSQL
- Docker
- Docker Compose
